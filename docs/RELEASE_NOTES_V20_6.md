# Ace's CFB Toolkit v20.6

## Release Notes

### Roster Generator

- Updated tool version to 1.2.
- Generated players now receive fresh commentary identities instead of retaining the original player's full-name commentary.
- Clears existing injuries, fatigue, and wear-and-tear.
- Generates eligibility history consistent with each player's class year and redshirt status.
- Generates matching hometown, state, and recruiting pipeline combinations.
- Automatically reassigns team captains.
- Adds observed left/right-handedness variety, with QB equipment adjusted accordingly.
- Statistics, awards, and depth charts remain untouched. Reordering your depth chart in-game after generation is recommended.

### Dealbreaker Fixer

- Ideal recruiting pitches now update to match newly assigned dealbreakers, both in the standalone tool and during roster generation.

### General

- Expanded reporting and save-verification checks for these changes.

This is a source update; publishing it does not create or replace an installer release. Installer/update version is 20.6.0. Generated rosters still need in-game checks for commentary audio, health, captain patches, and progression.
