# Ace's CFB Toolkit v20.7

## Release Notes

### General

- Automatic update prompts now use the Toolkit's own window style instead of basic Windows dialogs.

### Roster Generator

- Position Strength now shows live target OVRs alongside talent shares.
- Added individual team settings when regenerating multiple rosters. Customize caliber, age, potential, position strength, schemes, appearance, and depth-chart handling separately for each team.
- Surnames now use observed skin-tone/name pools rather than one shared surname list. Existing first-name/face pairing, suffixes, and hyphenated names are retained.
- Running backs and corners are more likely to have darker skin tones, including with the Big Sky preset.
- Added optional automatic depth-chart reordering based on natural positions, overall ratings, and specialist skills. Existing locks are respected, and unsupported/shared charts are left unchanged with an explanation.
- Lowered All-Time Team's target average player OVR to 81.
- Fixed blocked generation for players whose Base appearance layer contains supported tattoo slots, including the supplied Jackson State roster. Unknown appearance layers still block Apply to protect the save.
- Added depth-chart changes and team-specific settings to previews and reports.

Test generated copies in-game before continuing a dynasty. Toolkit verification cannot independently prove all depth-chart/game behavior. Nothing is uploaded or published by local packaging.
