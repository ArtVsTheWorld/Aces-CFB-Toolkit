### Release Notes

General
- Most settings/filters now open up into modals, significantly reducing settings clutter
- More UI/UX improvements

Equipment Randomizer
- Added the new white Nike/Battle skullcaps to the RAW Accessories pool

Equipment Patcher
- Helmet pass settings now live together in one panel: “Repair Only” replaces only unsupported helmets with your custom percentages. Setting a percentage to 0% marks that helmet as unsupported. “Apply My Mix” adjusts the global helmet distribution toward your percentages
- Expanded helmet configuration to all position groups, including OL, and added configurable facemask pools
- Rolled jersey undershirt replacement percentages are now configurable
- “Hand Out Visors” pass now uses configurable percentage limits by position group
- Tape color is now set to match accessory color by default. The option to configure by team still exists

Smart Force Win
- Added custom matchup-model sliders, allowing users to configure the weights of all the different factors the force win tool takes into account

Commentary IDs
- Better handling for suffix names (Jr. / Sr. / Roman Numerals)
