# Ace's CFB Toolkit

A Windows desktop toolkit for College Football 27 Dynasty saves.

## Download

Open [the latest release](https://github.com/ArtVsTheWorld/Aces-CFB-Toolkit/releases/latest)
and download the **Aces-CFB-Toolkit-Setup** EXE. Close any old portable copy,
run the installer, and launch the installed app.

The installer edition checks for new releases when it opens. You choose when
to download an update and restart to install it. You can also check manually
in **Settings → App Updates**.

Keep your save backups. Review proposed changes before applying any tool.
Some optional equipment settings require the corresponding external mod;
those mods are not included in this download.

This repository hosts release downloads and patch notes, not the development
source or user saves. The `.blockmap` and `latest.yml` release attachments are
used by the updater; users only need to download and run the Setup EXE.

The installer is currently unsigned, so Windows may show an unknown-publisher
warning. Download only from this repository's official releases.
