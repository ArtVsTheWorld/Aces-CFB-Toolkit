# Cutoff pants outfit adjustment

Adjust Outfit for Cutoff Pants is checked by default in the Patcher's Cutoff
Pants Fit & Rules page. Explicit saved false values remain false; older presets
without this setting use the new checked default. The Unlocked Quickstart
configuration enables the same behavior. Randomizer-only runs do not enable it.

Only selected cutoff recipients can be adjusted. Compatible jerseys stay;
other jerseys change to the verified Rolled Lowest Untucked style. A missing
undershirt becomes the verified Primary Sleeveless Compression Undershirt.
Known Relaxed Tee conflicts are checked after the jersey choice and use the
matching verified compression-shirt color. Other compatible undershirts stay.

Active or unknown leg base layers still exclude a candidate. The option never
removes leg layers, bypasses player protection, edits shared appearances, raises
the configured frequency, or enables Below-Knee Pants replacement by itself.
The existing Below-Knee Pants override remains separate and off by default.
Turning adjustment off preserves the earlier skip behavior.

Candidate fitting runs on clones. Accepted changes to jersey, undershirt and
pants are applied together and included in grouped preview rows and full CSV
appearance audits. Existing element metadata, unselected appearances, caps,
save-storage fitting and atomic save/reopen checks remain in force.
