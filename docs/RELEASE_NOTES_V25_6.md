### Release Notes

General

- Save picker now rejects mod files and other invalid files with a warning. Accepted save types depend on which tool you're using

Equipment Tools

- Equipment tools now automatically protect your RTG player from changes and exclude them from donor selections
- Randomizer, Quickstart and Roster Generator now keep accessory colors coordinated within each player, even without Recolor Accessories. Fixed-color items and custom item selections are still respected

Equipment Randomizer and Equipment Quickstart

- Added RAW Accessories v3.2.1 support, including pink gloves and eight black towel positions. Pink gloves and black towels are disabled by default
- Added the eight base-game directional towels to the CFB 27 Equipment pool, with a default 1% chance
- Added Unlocked's Balaclava (Under Lip) options, disabled by default
- Quickstart is less likely to combine Compression Tees with arm sleeves, reducing the double-sleeve look while keeping some variety

Equipment Patcher

- Added a Cleat Colors tab to Recolor Accessories. Choose one Unlocked cleat color override per team, applied to both feet
- Cleat overrides are disabled by default. When enabled, Alabama, Georgia, USC, Penn State and Nebraska default to Black Cleats; other teams default to No Change
- Added a red warning that cleat color overrides replace existing spats
- Updated North Carolina's default accessory distribution in Patcher and Quickstart to 90% white and 10% primary, with no black or secondary

Roster Generator

- Added a Match Existing caliber option that targets each team's current average player OVR
- Fixed generation being blocked by additional appearance layers, edited heads and tattoos. Replaced players now receive fully rebuilt appearances
- Equipment generation now follows Quickstart's no-mod setup, including the CFB 27 Equipment pool, accessory reduction and QB glove protections
- Improved notices to identify affected players by name, jersey number and position
