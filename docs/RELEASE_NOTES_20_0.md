### Release Notes

General
- Additional filters/options for almost every tool
- Equipment compatibility improvements
- More UI/UX improvements
- Bug fixes

Equipment Randomizer
- Added new Raw Accessories backplates to its equipment pool
- Both modded equipment pools are now configurable
- Can now configure cross-position donor sources by position group
- Can now use a roster file as the source for equipment donation rather than just a dynasty file

Equipment Patcher
- Can now configure facemask pools by position
- Added an Unlocked-only modded socks pass that replaces vanilla mid and high socks with Unlocked’s scrunched variants
- Added “Clear Tattoos” pass that removes tattoos
- Leg tattoos no longer change the player's socks
- Mouthpiece style percentages and enable/disable controls, per-position

Smart Force Win
- Added “User Schedule Only” option

Jersey Renumber
- Customizable retired numbers
- Create-Your-Own jersey number traditions
- Individual number locks

Commentary IDs
- Hyphenated last names try the full name first, then the final part: Josh-Johnson → Johnson
