# Ace's CFB Toolkit — Changes Since v18.3

## v18.4 — Equipment Reliability

- Fixed the Randomizer error that could say **“Equipment row … lost data during encoding.”** Certain saves stored equipment names differently, and the Toolkit now preserves them correctly. Equipment Patcher benefits from the same fix.
- Backups and save checks remain in place. The fix does not bypass them or blacklist affected players.

## v18.5 — More Control Over Equipment

- **Customize helmet usage.** Open **Configure Helmet Mix** in Equipment Patcher to set whole-number percentages for 14 supported helmet models, including LIGHT Gladiator and additional VICIS models. Set a mix for everyone or override individual positions. F7 and F7 Pro can have different percentages.
- **Keep the defaults or balance existing helmets.** Default Mix keeps the usual rules. Custom Mix changes replacement choices; enable **Balance Existing Helmets** to move existing helmets toward your targets too. The preview shows before/after counts, with FBS and directional FCS totals kept separate. Offensive linemen remain outside this pass.
- **Bears Pads sleeve fix.** A new optional pass fixes Double, Padded, and Compression Sleeves on Standard-body players. Choose Shooter Sleeve, No Sleeve, or a 50/50 mix. Shooter replacements keep the sleeve's color. **Requires Bears Pads.** Disabled by default.
- **Remove handwarmers.** A new optional pass removes handwarmers without removing waist playcall bands. Disabled by default.
- **Waist playcall colors.** Recolor Accessories supports their verified white, black, and primary-color variants. A nonexistent secondary-color variant is not substituted.
- **Brand Existing Visors now starts disabled.** You can still enable it when you want it.
- **More commentary matches.** Added 63 verified last-name/commentary pairings from BASEDEFAULT, including additional suffix-name variants.
- **Cleaner sidebar icons.** Dealbreaker Fixer and Smart Force Win now use icons that match the rest of the app.

**Versions:** App v18.5 · Equipment Randomizer v5.1 · Equipment Patcher v5.3 · Commentary ID Patcher v2.0.

Save protections, reviewed-plan Apply, backups, and existing mod requirements remain in place. Unlocked/Raw mods and Bears Pads are not included with the Toolkit.
