### Release Notes

General

- Major UI/UX overhaul throughout the app, with more consistent spacing, alignment, buttons, filters, and configuration windows
- Rebuilt settings flows around choosing the options you want first, then configuring only those options, while retaining the existing level of control
- Moved longer option explanations into info buttons and organized more settings into tabbed windows to reduce clutter
- Redesigned preview and results pages to prioritize affected players and teams, clearer summaries, and the changes being made. Reports, diagnostics, and additional run details are tucked away until needed
- Added a separate Main Color setting alongside Accent Color. Main Color tints the darker parts of the app, while light-mode backgrounds remain neutral
- The in-app wrench icon now follows your selected accent color
- Updates now include a What's New window showing the release notes from GitHub
- Improved save-selection and loading speed, with visible progress while a save opens

Home

- Reorganized Quick Tools and Recent Activity, with the recommended workflow shown at the top only during preseason
- Redesigned Season Matchup Lines with larger team logos and names, aligned spread/moneyline/total tiles, and a cleaner away-at-home layout
- Improved spacing below team artwork and between Home sections
- Moved Customize Team Art into the main Home header button, removing the duplicate Change Save button

Equipment Quickstart

- Added an option to disable protection of original EA roster players
- When Unlocked is enabled, Quickstart now includes tattoos using Fill to Frequency at 35%
- Kickers and punters now use donor equipment only and are excluded from modded equipment pools

Equipment Randomizer

- Added a Clear Save Memory button alongside the existing player-memory controls
- Fixed overlapping modded-pool assignments in Randomizer and Quickstart so one pool no longer overwrites another pool's successful selection for the same equipment slot

Equipment Patcher

- Recolor Accessories now defaults to Team Percentage Distributions, with tape set to Match Player Accessory Color

History, Reports, and Team Artwork

- Run activity now follows the dynasty rather than its filename, so manual saves, autosaves, and renamed copies from the same dynasty share their history
- Custom team logos and headers are now saved separately for each dynasty and shared between saves from that same dynasty
- Added All Dynasties / This Dynasty filtering to History
- Added pagination to Reports and improved History's filter layout. Both pages reopen at the first page
